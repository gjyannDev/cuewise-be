# Frontend fundamentals

## HTML, CSS and accessibility
Probe semantic HTML, a layout they built with flexbox or grid, and how a keyboard or screen-reader user would use it. Strong answers mention labels, focus order and contrast without being prompted. Weak answers style divs for everything.

## JavaScript and the DOM
Ask how an event reaches a handler, what async code does while waiting, and how they would debug a click that does nothing. Strong answers use the browser devtools and explain promises in plain words.

## Component state
Probe where state should live in a small form: local state, lifted state, or derived values. Strong answers avoid duplicating state and explain why a component re-renders.
