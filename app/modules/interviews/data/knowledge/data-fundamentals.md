# Data fundamentals

## SQL for analysis
Probe a question they answered with SQL: grouping, joins that duplicate rows by mistake, and window functions for running totals. Strong answers check row counts after each join.

## Cleaning messy data
Ask about missing values, duplicates and wrong types in a real dataset. Strong answers explain each choice (drop, fill, flag) and its effect on the result, and keep the raw data untouched.

## Communicating a result
Probe how they presented a finding: the chart they chose, the caveats they stated, and what the audience decided. Strong answers lead with the answer to the question, not the method.
