# Mobile fundamentals

## App lifecycle
Probe what happens when the app goes to the background, is killed by the system, or is reopened from a notification. Strong answers save user input before it is lost and restore the screen the user expects.

## Layouts across screen sizes
Ask how they make a screen work on a small phone, a large phone and a tablet, with large text turned on. Strong answers mention safe areas, scrolling and testing on real devices.

## Networking on unreliable connections
Probe what the user sees on a slow or dropped connection: loading states, retries, timeouts and an error with a way out. Weak answers assume the request always succeeds.
