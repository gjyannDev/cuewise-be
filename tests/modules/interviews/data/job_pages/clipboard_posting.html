Data Engineer

Northwind Analytics Makati City, Metro Manila Full time

Northwind Analytics helps retailers forecast demand. We are looking for a data engineer to build and run the pipelines that feed our forecasting models.

Responsibilities

  • Build batch and streaming pipelines in Python, SQL and Apache Airflow
  • Model warehouse tables in BigQuery and keep them documented
  • Work with analysts to turn requirements into reliable datasets

Qualifications

  • Three years of experience in data engineering
  • Strong SQL and Python skills
  • Experience with a cloud data warehouse

Benefits: HMO from day one, hybrid work, and a yearly learning budget.
