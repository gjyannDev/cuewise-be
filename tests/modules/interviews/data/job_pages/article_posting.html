Frontend Developer (React)

Brightside Studio builds booking software for independent fitness studios. We are hiring a mid-level frontend developer to join a team of six engineers working on our customer-facing web app.

What you will work on

  • Building accessible React components with TypeScript and a shared design system
  • Improving page performance and Core Web Vitals on the booking flow
  • Writing tests with Vitest and Playwright and keeping the build green

What we are looking for

  • Three or more years of professional experience with React and TypeScript
  • Good understanding of state management, data fetching and caching
  • Comfort giving and receiving code review

This role is remote within Europe, with a team meetup twice a year.
